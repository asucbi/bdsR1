\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  Create a new dataset that includes only weeks 2-6.
\item
  Relevel the condition factor so the legend appears in this order: No
  intervention, Expressive writing, Mindfulness, Cognitive reappraisal
\item
  Create a line graph showing mean stress score over time.

  \begin{itemize}
  \tightlist
  \item
    x-axis: week
  \item
    y-axis: mean\_stress\_score
  \item
    color: condition
  \end{itemize}
\item
  Knit your file as a .pdf and upload it to Module 5: Quiz on Canvas.
\end{enumerate}
